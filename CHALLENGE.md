# Command Line Challenge - solution

All commands were run from the repository root in a Codespaces terminal.

| # | Challenge | Command |
|---|---|---|
| 1 | Get inside the thecmdchallenge directory | `cd thecmdchallenge` |
| 2 | List all files, including hidden ones | `ls -a` |
| 3 | Print the current directory path | `pwd` |
| 4 | Clear the terminal | `clear` |
| 5 | List all files recursively | `ls -R` |
| 6 | Go to the last level below small-name and show trophy.txt | `cd small-name/bigger-name-than-before/omg-.../this-is-probably-.../` then `cat trophy.txt` |
| 7 | Move up to funcode and list the JavaScript files | `cd ../../../../funcode` then `ls *.js` |
| 8 | Create funcode/the-most-funny/not-that-funny | `mkdir the-most-funny/not-that-funny` |
| 9 | Copy the-mostboring-text.txt as lol.txt | `cp boringfolder/.../the-ultimate-boring-inception/the-mostboring-text.txt boringfolder/.../the-ultimate-boring-inception/lol.txt` |
| 10 | Move funcode/kids.jpg into funcode/images/hello/ | `mv funcode/kids.jpg funcode/images/hello/` |
| 11 | Remove the small-name directory | `rm -r small-name` |
| 12 | Print the-ultimate-joke.txt | `cat funcode/the-most-funny/lol/the-ultimate-joke.txt` |
| 13 | Remove all the contents of boringfolder | `rm -r boringfolder/*` |
| 14 | Open kamehameha/dragon-ball-jokes.md with vi | `vi kamehameha/dragon-ball-jokes.md` |
| 15 | Remove the first joke, save and close | `2dd` on the first line, then `:wq` |

`.gitkeep` files keep the empty `not-that-funny` and `boringfolder` directories in Git.
